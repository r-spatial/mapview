# Print functions for mapview objects used in knitr

Print functions for mapview objects used in knitr

## Usage

``` r
# S3 method for class 'mapview'
knit_print(x, ...)
```

## Arguments

- x:

  A mapview object

- ...:

  further arguments passed on to
  [`knit_print`](https://rdrr.io/pkg/knitr/man/knit_print.html)
